## Dataset Structure
The dataset contains categorized spoken dialogue lines for 4 distinct Non-Player Character (NPC) archetypes:
1. `garrick_blacksmith` (Garrick the Grumpy Blacksmith) - Gruff, mechanical, trade-oriented vocabulary (iron, anvil, hammer, forge, coal, blade).
2. `elindra_mage` (Elindra the Cryptic Mage) - Arcane, contemplative, mystical phrasing (stars, ether, runes, veil, prophecy, shadows).
3. `pip_bard` (Pip the Cheerful Bard) - Joyful, musical, lively vocabulary (ballad, tankard, cider, tavern, dance, lute, laughter).
4. `kaelen_rogue` (Kaelen the Shadow Rogue) - Stealthy, cautious, underworld-focused phrasing (daggers, shadows, coin, traps, alleyways, whisper).

## File Formats
- `dialogues.json`: Structured array of dialogue entries with `character`, `character_name`, and `text`.
- `dialogues.txt`: Plain-text paired format (`[character_id] dialogue text`) for quick line-by-line inspection.
